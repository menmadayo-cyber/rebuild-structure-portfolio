# 入力例｜文書校正

以下は、取引先への連絡メールの下書きを例にした入力サンプルです。実際にプロンプトへ貼り付ける際は、自分が校正してほしい文章に書き換えてください。

```
校正してほしい文章は以下の通りです。

いつもお世話になっております。
先日ご相談させていただいた件についてなんですが、社内で検討した結果、
来月からの導入を進めていく方向で話がまとまりました。
つきましては、詳細な進め方について、一度お打ち合わせのお時間を
いただけたらなと思っております。
来週以降でしたらこちらは基本いつでも大丈夫なので、
ご都合の良い日時をいくつか教えていただけますと助かります。
よろしくお願いいたします。
```

## 書き方のポイント

- 話し言葉が混ざっていたり、言い回しが冗長だったりしても構いません。そのままの状態で貼り付けてください。
- メール・社内文書・お知らせ文など、文章の種類は問いません。
- 取引先名・個人名など、公開・共有したくない情報が含まれる場合は、仮名や記号に置き換えてから使用してください。
