# 03｜文書校正

メールや文書を貼り付けるだけで、意味をできるだけ変えずに読みやすい文章へ整えるテンプレートです。文章を書くのに時間がかかる、言い回しに自信が持てない、という方に向けています。

## 使い方

1. [prompt.md](prompt.md)の内容を全文コピーする
2. ChatGPT・Claude・Geminiなど、使い慣れた生成AIに貼り付ける
3. プロンプト内の指示に従い、校正してほしい文章を書き加える（書き方に迷う場合は[sample-input.md](sample-input.md)を参考にする）
4. AIの回答を確認する（出力イメージは[sample-output.md](sample-output.md)を参照）
5. 修正後の文章をそのまま使わず、自分の意図と合っているか確認してから使用する

## ファイル構成

| ファイル | 内容 |
|---|---|
| `prompt.md` | AIに貼り付けるプロンプト本体 |
| `sample-input.md` | 校正してほしい文章の書き方の例 |
| `sample-output.md` | AIの回答イメージ |

## 使う上での注意

- AIによる修正で、細かなニュアンスが変わってしまう場合があります。送信前に必ず自分で読み返してください。
- 取引先とのやり取りなど、社外に送る文章に個人名・企業名が含まれる場合は、生成AIへの入力可否について社内ルールを確認してください。
