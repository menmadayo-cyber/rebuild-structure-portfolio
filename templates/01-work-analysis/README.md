# 01｜業務整理・AI活用ポイント発見

普段行っている仕事の内容を書き出すことで、

- AIで支援できる部分
- 自動化できる部分
- AIと自動化を組み合わせられる部分
- 人が対応すべき部分
- 現状のままでよい部分

を整理するテンプレートです。

「AIを使ってみたいが、何から手をつければよいか分からない」という段階の方に向けています。

## 使い方

1. [prompt.md](prompt.md)の内容を全文コピーする
2. ChatGPT・Claude・Geminiなど、使い慣れた生成AIに貼り付ける
3. プロンプト内の指示に従い、自分の業務内容を書き加える（書き方に迷う場合は[sample-input.md](sample-input.md)を参考にする）
4. AIの回答を確認する（出力イメージは[sample-output.md](sample-output.md)を参照）
5. 分析結果をA4・1ページ程度の業務改善レポートとして整理したい場合は、続けて[report-prompt.md](report-prompt.md)を使う

## ファイル構成

| ファイル | 内容 |
|---|---|
| `prompt.md` | AIに貼り付けるプロンプト本体 |
| `sample-input.md` | 業務内容の書き方の例 |
| `sample-output.md` | AIの回答イメージ |
| `report-prompt.md` | 分析結果をA4・1ページ程度の業務改善レポートとして整理する追加プロンプト |

## 使う上での注意

- AIの回答は、実際の業務内容や職場の事情によって当てはまらない場合があります。あくまで整理の「たたき台」として使ってください。
- 会社の機密情報や個人が特定される情報（取引先名・顧客名・具体的な金額など）は、生成AIへの入力を避け、抽象化した表現に置き換えてから使ってください。
