# 入力例｜月次実績レポート作成

## 私の業務情報

【業務名】
月次実績レポート作成

【この業務の目的】
各部署の実績を集計し、前月からの変化や主なポイントを上司へ報告する。

【誰が行っている業務か】
営業企画担当者1名

【現在の作業内容・流れ】
1. 各部署からExcelをメールで受け取る
2. 必要な数値を集計用Excelへ転記する
3. 前月実績と比較する
4. 数字が大きく変化した項目を確認する
5. 各部署のコメントを確認する
6. 報告コメントを作成し、上司へメールする

【業務の頻度】
月1回

【おおよその作業時間】
約3時間

【現在使っているツール】
Excel、Outlook、社内共有フォルダ

【困っていること・改善したいこと】
- 毎月同じ転記作業がある
- 転記ミスの確認に時間がかかる
- 前月との差を探すのに時間がかかる
- 報告コメントを毎回一から考えている
- 作業が担当者に属人化している

【業務上のルール・制約】
- 機密情報や個人情報を社外サービスへ入力できない
- 最終的な報告内容は担当者が確認する必要がある
