# 02｜議事録整理

会議のメモや文字起こしを貼り付けるだけで、会議の概要・決定事項・ネクストアクションに整理できるテンプレートです。会議で決まっていないことは「要確認」として扱い、勝手に決定事項にしないよう設計しています。会議後の議事録作成に時間がかかっている方に向けています。

## 使い方

1. [prompt.md](prompt.md)の内容を全文コピーする
2. ChatGPT・Claude・Geminiなど、使い慣れた生成AIに貼り付ける
3. プロンプト内の指示に従い、会議メモや文字起こしを書き加える（書き方に迷う場合は[sample-input.md](sample-input.md)を参考にする）
4. AIの回答を確認する（出力イメージは[sample-output.md](sample-output.md)を参照）
5. 内容に誤りや過不足がないか、必ず自分で確認・修正する

## ファイル構成

| ファイル | 内容 |
|---|---|
| `prompt.md` | AIに貼り付けるプロンプト本体 |
| `sample-input.md` | 会議メモ・文字起こしの書き方の例 |
| `sample-output.md` | AIの回答イメージ |

## 使う上での注意

- AIはメモに書かれていない内容を推測で補うことがあります。決定事項・ネクストアクションは特に、実際の会議内容と照らし合わせて確認してください。
- 参加者名・取引先名など、個人や企業が特定される情報を含む場合は、生成AIへの入力可否について社内ルールを確認してください。
