# セットアップ｜ローカル環境での確認方法

本サイトはビルド処理・パッケージインストールが不要な静的HTML/CSS/JSサイトのため、`npm install`等は行わず、ローカルサーバーを起動して直接確認する。

## 必要な環境

以下のいずれか一方があれば確認できる（両方は不要）。

- Python 3（`python`コマンドが使えること）
- Node.js（`npx`コマンドが使えること）

## 起動方法

このリポジトリのルートディレクトリで、以下のいずれかの方法でローカルサーバーを起動する。

### Pythonを使う場合

```bash
python -m http.server 8080
```

起動後、ブラウザで `http://localhost:8080/` を開く。

### Node.js（npx）を使う場合

```bash
npx serve .
```

表示されたURL（例：`http://localhost:3000/`）を開く。

## 注意

- `index.html`を直接ブラウザで開く（`file://`）方式でも大部分は表示できるが、相対パスの検証のため、上記のローカルサーバー経由での確認を推奨する。
- スマートフォン表示は、ブラウザの開発者ツール（デバイスツールバー）でビューポート幅を切り替えて確認する（360px・390px・768px・1024px・1440px目安）。同一Wi-Fi内の実機で確認する場合は、サーバーを`0.0.0.0`（全インターフェース）で起動し、PCのローカルIPアドレス（`ipconfig`で確認）にスマートフォンからアクセスする。

## 公開用ビルドの確認（任意）

Cloudflare Pagesが実行する公開用ファイルの選別処理を、ローカルでも同じコマンドで再現できる。

```bash
node scripts/build-static.mjs
```

`dist/`に公開対象ファイルのみが生成される（ビルドコマンド・出力先の詳細は`docs/deployment-guide.md`参照）。日常的なコンテンツ編集の確認には必須ではないが、コミット前の最終確認として使うとよい。
