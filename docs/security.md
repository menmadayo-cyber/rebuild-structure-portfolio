# セキュリティ・機密情報の取り扱い

- 本サイトはビルド処理・サーバーサイド処理を持たない静的サイトであり、**APIキー・パスワード・トークン等の機密情報を含める必要は本来ない**。
- お問い合わせは外部サービス（Googleフォーム）を利用しており、送信先エンドポイントやAPIキーをHTML・CSS・JSに直接書き込む実装は行っていない。今後、新たに外部API連携（アクセス解析等）を追加する場合も、キーやシークレットをクライアント側コードに埋め込まずに済む方法を優先して検討する。
- `.env`等の環境変数ファイルを作業用に作成した場合は、`.gitignore`で除外済みだが、**コミット前に`git status`で意図せず含まれていないか必ず確認する**。
- 個人が特定される情報（実際の顧客データ・取引先名等）は、本文・画像とも掲載しない方針を徹底している。制作事例のスクリーンショット等を追加する際も同様に確認する。
- 本サイトのドメイン・問い合わせ先はすでに確定済みであり、未確定のプレースホルダー表記は残っていない。
