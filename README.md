# Rebuild Structure

AI業務改善・自動化 × 実践テンプレート

## 1｜このリポジトリについて

Rebuild Structureは、業務改善・生成AI・自動化を組み合わせ、
「現場の頑張りで回る業務を、仕組みで回る業務へ」変えていく取り組みです。

このリポジトリでは、AI初心者でも試せる業務活用テンプレートや、実際に制作・運用した事例を公開しています。

## 2｜AI初心者の方へ｜まずはここから

ChatGPT・Claude・Geminiなどを使ったことはあるものの、

- 「何を入力すればいいか分からない」
- 「自分の仕事で何に使えるのか分からない」

という方向けに、コピペして試せるテンプレートを用意しています。

### 使い方

1. 使いたいテンプレートを選ぶ
2. プロンプトをコピーする
3. ChatGPT / Claude / Geminiに貼り付ける
4. 自分の業務情報を入力する
5. AIの回答を確認・修正する

## 4｜制作・活用事例

AI・自動化を、実際の業務や課題に合わせて形にした事例です。

### 01｜AI Secretary App

Googleアカウントでログインし、Googleカレンダーとの連携や、議事録作成・文書校正などを行えるAI業務支援Webアプリです。

生成AIや外部サービスを組み合わせ、日々の業務を支援する仕組みをプロトタイプとして開発しました。

[詳細を見る](https://rebuild-structure.jp/works/ai-secretary-app.html)

### 02｜スキーイベント運営のデジタル化

実際に運営するスキーイベントで、Webサイト・申込フォームを制作し、参加受付から参加者情報の管理、メール連絡までをデジタル化しました。

複数のツールを組み合わせ、実際のイベント運営で使用できる仕組みとして構築・運用しています。

[事例を見る](https://rebuild-structure.jp/works/event-automation.html)

### 03｜Makeを活用した業務自動化

フォームへの入力をきっかけに、受付メールの送信、Slackへの通知、Google Sheetsへの情報記録などを自動実行するワークフローを構築しました。

繰り返し発生する定型業務を整理し、ノーコードツールを使って自動化した事例です。

[デモを見る](https://rebuild-structure.jp/works/make-automation-demo.html)

## 5｜Rebuild Structureについて

Rebuild Structureでは、AIを導入すること自体を目的にするのではなく、まず業務や課題を整理し、必要な部分に生成AI・自動化・業務支援ツールを組み合わせることを重視しています。

現場で実際に使える形まで落とし込み、AIに詳しくない方にも分かりやすく使える仕組みを目指しています。

主に、以下の領域に取り組んでいます。

- **AI業務改善・自動化支援**
  業務を整理し、AI・自動化を活用して「仕組みで回る業務」へつなげます。

- **AIエージェント・業務支援ツール開発**
  業務上の課題やアイデアを、AIを活用したツールやプロトタイプとして形にします。

- **生成AI研修・導入支援**
  ChatGPTなどの生成AIを、非エンジニアにも分かりやすく、実際の業務で使える形で支援します。
